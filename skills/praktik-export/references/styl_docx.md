# Styl docx pro kurzy PRAKTIK-AI

| Prvek | Nastavení |
|---|---|
| Základní písmo | Arial 11 pt, řádkování 1,15, mezera za odstavcem 6 pt |
| Název kurzu (H1 první) | Arial 20 pt tučně, barva #1F5C99 (PRAKTIK-AI modrá) |
| Podtitul (### pod názvem) | Arial 12 pt kurzíva, šedá #595959 |
| Záhlaví modulu / capstone / testu / zdrojů (`# …`) | Arial 14 pt tučně, bílé písmo, podklad #1F5C99, odstup před 18 pt, za 6 pt |
| Nadpis sekce (`## …`) | Arial 13 pt tučně, #1F5C99, odstup před 12 pt |
| Nadpis fáze (`## F1 …`) | stejné jako sekce, plus tenká spodní linka #9DC3E6 |
| Výkladový odstavec (F1) | zarovnání do bloku |
| Kurzivní odstavec (IMPULS, Zapamatujte si, instrukce pro agenta) | kurzíva, odsazení zleva 0,8 cm, levý rámeček 6 pt #9DC3E6, mezera 4 pt |
| Blockquote (`> …`, poznámka pro garanta) | odsazení 0,8 cm, podklad #FFF4CE, levý rámeček #C9A227 |
| Tabulky | Table Grid, záhlaví tučně na #DEEAF6, písmo 10 pt, šířka na okraje |
| Seznamy | číslované List Number, odrážky List Bullet; odsazené podpoložky (a) b) c)) jako List Bullet 2 |
| Inline | `**tučně**` → bold, `*kurzíva*` → italic, `✓` zůstává |
| Zápatí | Arial 8 pt, šedá: „Zdroj: … · Vzniklo v projektu TQ23000092 PRAKTIK-AI (TA ČR, program SIGMA) · <KOD> v<verze>, <datum>“ + číslo strany vpravo |
| Okraje | 2,5 cm, A4 |
| Konec dokumentu | řádek s datem exportu a poznámkou „Verze pro oponenturu / pro platformu“ |

Logo se do docx nevkládá (docx je pracovní dokument pro autora a oponenta). Loga patří na titulní slide videa, viz skill av-materialy.
